## 🌦️ About the Project

**Weather Finder** is a web application developed using HTML, CSS, and JavaScript. It uses the Open-Meteo API to retrieve weather information for a city selected by the user.

The application uses city search and API requests to display weather details dynamically, with loading feedback and error handling.

## ✨ Features

- 🔎 **City Search** — Enter a city name to retrieve its weather information.
- 🌡️ **Temperature** — Display the reported temperature.
- 💧 **Humidity** — View humidity information when returned by the weather data.
- 🌬️ **Wind Speed** — Display the reported wind speed.
- ☁️ **Weather Conditions** — View the available weather condition information.
- ⏳ **Loading State** — Provide feedback while weather data is being retrieved.
- ⚠️ **Error Handling** — Handle unsuccessful requests or cities that cannot be found.
- 📱 **Responsive Interface** — A web interface designed to work across different screen sizes.

## 🚀 Run the Project Locally

**Step 1 — Clone the repository**

```bash
git clone https://github.com/Myths2005/weather-finder.git
```

**Step 2 — Open the project**

Open the downloaded folder in Visual Studio Code.

**Step 3 — Run the application**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

**Step 4 — Search for weather**

Enter a city name and view the weather information returned by the API.

> This project uses Open-Meteo's public weather services and does not require a conventional API key for its standard endpoints.
